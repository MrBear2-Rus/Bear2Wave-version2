环境变量
修改后需重启 Bear2Wave

大文件与加载

变量默认说明
BEAR2WAVE_LOAD_MARGIN0.2视口外预加载边距
BEAR2WAVE_TRACE_LOAD_DEBOUNCE_MS120后台加载防抖 ms
BEAR2WAVE_CACHE_DEBOUNCE_MS75绘制缓存防抖 ms
BEAR2WAVE_MAX_LOADED_CHANGES0跳变上限+LRU，0=关
BEAR2WAVE_IDX_CACHE1FST .bwidx 侧车
BEAR2WAVE_COMPACT_VC11-bit 紧凑存储

VCD

变量默认说明
BEAR2WAVE_VCD_WARN_MB50大 VCD 警告 MB
BEAR2WAVE_VCD_LAZY-1自动/强制/关闭 lazy
BEAR2WAVE_VCD_LAZY_MB10自动 lazy 阈值

绘制 / AI / 调试

变量默认说明
BEAR2WAVE_MAX_SEGMENTS5000绘制 LOD 段数上限
BEAR2WAVE_CACHE_THREADSCPU缓存构建线程
BEAR2WAVE_AI_MAX_EDGES_PER_SIG200AI 每信号采样
BEAR2WAVE_AI_MAX_CONTEXT_CHARS30000AI 上下文上限
BEAR2WAVE_FST_DEBUG—=1 FST 详细日志
BEAR2WAVE_WAVE_DEBUG—=1 波形逐帧日志

# PowerShell 示例
$env:BEAR2WAVE_VCD_LAZY = "1"
$env:BEAR2WAVE_MAX_LOADED_CHANGES = "50000000"

内存粗算：信号数 × 视口跳变数 × 9~72 B/跳变
