AI 与本地分析

本地分析（无需网络）

Ctrl+Shift+A 打开 AI 面板 → Notebook：

  • 本地统计 — 边沿、占空比、周期、X/Z、毛刺
  • 区间 — Marker A–B、Setup 粗查、Compare
  • 总线 — hex 时间线、最常见值、ASCII 预览
  • 规则 — valid/ready、双信号对比、竞赛清单

点击 刷新统计 / 完整报告，可导出或「送 AI 解释」。


AI 分析（DeepSeek / Ollama）

  1. AI → Set API Key（存于 %APPDATA%\Bear2Wave\config.ini）
  2. 波形区添加信号 → 从波形刷新
  3. 选模板 → AI 分析（后台，可取消）
功能说明
右键 AI Analyze单路信号分析
多轮对话保留最近 K 轮
跳转时间从回复解析时间戳
