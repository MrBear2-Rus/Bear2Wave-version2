概述与快速入门

什么是 Bear2Wave？

Bear2Wave 是面向 RTL 仿真的波形查看器，操作习惯参考 GTKWave，并增强：

  • 大文件懒加载 — FST / VZT / LXT2 / GHW / VCD(lazy) 先开层次，再按视口加载跳变
  • Compare 双窗 — 两路轨迹联动播放头与时间视口
  • AI 分析 — DeepSeek 或 Ollama 本地，解读视口内波形摘要
  • 本地统计 — 边沿、占空比、毛刺、握手规则，无需 API Key
推荐工作流
仿真输出 .fst → 只添加需要的信号 → 平移/缩放定位 → Marker 测量 → 本地报告 / AI → 保存 .bwv 会话

5 分钟上手

1. 打开波形

File → Open Trace… 或快捷键 Ctrl+O

推荐首次体验：tests/traces/bear2wave_sample.fst

2. 添加信号

  1. 左侧展开 VCD Modules 模块树
  2. 点击模块，右侧信号列表 双击 信号
  3. 信号出现在波形显示区
重要 — Bear2Wave 不会自动加载全芯片波形。只加载你加入波形区的信号，这是大文件可用的关键。

3. 浏览时间

  • 左键拖动 波形区 → 移动播放头（红色竖线）
  • 滚轮 → 缩放（Markers 菜单可切换为滚轮移时间）
  • From / To → 精确设置可见范围
  • Play → 自动播放播放头

4. 保存现场

Ctrl+S 保存 .bwv 会话，下次 Read Session 一键恢复。
