全局

快捷键功能
Ctrl+O打开波形文件
Ctrl+S保存会话 (.bwv)
Shift+Ctrl+S另存会话
Ctrl+Shift+AAI 面板开关
Ctrl+Shift+F聚焦信号搜索
Ctrl+Shift+OCompare 第二轨迹
Ctrl+Shift+L调试日志窗口
Ctrl+F1打开帮助
Esc取消加载 / 清除测量

Ctrl+← / →平移视窗
Home / End播放头首 / 末
Ctrl+Home / End视窗首 / 末
F1Move To Time
