区域说明

区域作用
模块树按设计层次浏览；展开路径写入 .bwv
信号列表当前模块信号；双击添加到波形区
波形区阶梯波形；左键播放头，Ctrl+左键 A/B 测量
AI 面板本地统计 + AI；Ctrl+Shift+A 开关
底栏搜索、缩放、滑块、Play、时间范围
