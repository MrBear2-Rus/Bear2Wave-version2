性能与调优

使用原则

  1. 仿真输出 FST，避免巨大 VCD
  2. 只添加调试需要的信号（10～50 路通常足够）
  3. 平移/缩放时 lazy 格式按需读块，状态栏有进度/ETA
  4. 按 Esc 可取消进行中的加载

常用环境变量

变量默认作用
BEAR2WAVE_LOAD_MARGIN0.2视口外预加载比例
BEAR2WAVE_VCD_LAZYautoVCD 懒加载
BEAR2WAVE_COMPACT_VC11-bit 紧凑存储
BEAR2WAVE_MAX_LOADED_CHANGES0跳变内存上限+LRU
BEAR2WAVE_MAX_SEGMENTS5000绘制段数 LOD

完整列表见 Help → 环境变量。
