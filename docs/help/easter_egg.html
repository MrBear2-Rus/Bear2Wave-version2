狗熊岭树洞宣言

本软件由熊二在狗熊岭的树洞里完成。

树洞里没有 GitHub Copilot，也没有熊大催你交代码，只有：

  • 一块从光头强那儿「借」来的旧显示器（他说会还，熊二信到了现在）
  • 松果垫显示器，蜂蜜当夜宵，FST 当主食——开完波形再舔罐盖
  • 树洞外风吹树叶的沙沙声当白噪音，偶尔当地钟 clk
  • 熊大在隔壁树洞喊「二货你又在干嘛」，权当 code review
官方（熊二口）声明
狗熊岭不属于任何 EDA 厂商。熊二不属于任何加班制度。
若波形仍不对，请先在树杈上深呼吸，再检查 rst 有没有真的释放。

验证工程师守则 · 熊二摸鱼修订版

#守则
1波形不对，先怀疑 testbench，再怀疑 DUT，最后怀疑是不是又打开了 50GB 的 VCD
2只加 clk 和 rst 也能 debug —— 和熊二只带一罐蜂蜜爬下树一样，极简但 somehow 能活
3FST 大法好；VCD 是健身器材，适合练臂力与 patience
4AI 说「逻辑看起来正确」≈ 还没帮你看 clk 对齐
5Marker 打在 0ns 不算测量，算许愿
6Compare 两路波形：若完全一样，要么设计真稳，要么你开重了
7保存 .bwv 会话 = 给未来的自己留一条爬出树洞的路
8Esc 取消加载：熊二也懂得「算了先吃口蜂蜜再说」
9深夜 debug 时，狗熊岭的月亮相当于 free logic analyzer（精度不保证）
10若 bug 在周五下午出现，它可能来自周一；若在上板前出现，它一定来自你刚改的那一行

树洞秘传快捷键（熊二认证 · 不一定生效）

按键功能
Ctrl+Alt+2召唤熊二（可能只出现 ASCII 熊头版）
Shift+Honey暂停仿真，注入虚拟蜂蜜（latency +∞）
F12 × 3把 X 态重新标记为「熊二还没想好」
Alt+树杈切换狗熊岭昼夜模式（仅改变心情）
Ctrl+0这个是真的：Zoom Full。熊二没骗你。

熊问熊答

Q：为什么叫 Bear2Wave？
A：Bear2 = 熊二。GTKWave 很好，但狗熊岭需要熊二，和一份能塞进树洞的懒加载。

Q：.bwv 是什么？
A：Bear Wave View。会话文件。下次爬下树不用重新点一遍 clk。

Q：AI 面板会取代验证工程师吗？
A：不会。AI 不会帮你在凌晨三点对波形说「再查最后一次」。熊二也不会——他那个点通常已经睡了。
